# Jan Suraaj PPT Automation

Python automation utilities for programmatic generation and styling of executive PowerPoint presentations and campaign review decks using `python-pptx`.

## 📌 Features
- **Dynamic Slide Construction:** Automatically places branded headers, timeline milestones, and data tables.
- **Documentary Narrative Deck:** Programmatically aggregates campaign stills, route maps, and operational metrics into structured slide templates.
- **Consistent Layouts:** Enforces standard 16:9 typography, color palettes, and slide layouts.

## 🚀 Execution
```bash
pip install python-pptx
python create_jansuraaj_ppt.py
```
